## 🌟 Highlights & Philosophy

**Happy Anniversary** elevates traditional digital greeting cards into an immersive, sensory keepsake. Designed with the precision of Cupertino Human Interface Guidelines (HIG), every element balances **Clarity, Deference, and Depth**.

The application is engineered to be **perpetual** — you configure a couple's wedding date once, and its dynamic milestone engine will automatically recalculate completed years, upcoming countdowns, and traditional anniversary themes (Paper, Wood, Silver, Gold, Diamond) for decades to come without changing a single line of code.

## ⚙️ Smart URL Parameter Sharing

Share personalized cards directly with loved ones by passing query parameters in the URL:

```text
https://rahul08319.github.io/Happy-Anniversary/?names=Rahul+%26+Pooja&date=2021-10-24&msg=Forever+and+always!
```

### Supported Parameters:

| Parameter | Type | Example | Description |
| :--- | :--- | :--- | :--- |
| `names` | `string` | `Rahul & Pooja` | Names of the celebrated couple |
| `date` | `YYYY-MM-DD` | `2021-10-24` | Wedding or relationship anniversary date |
| `msg` | `string` | `To a lifetime of adventures!` | Custom personal message or romantic wish |
| `photo` | `URL` | `https://example.com/photo.jpg` | Custom photo displayed in the keepsake Polaroid |

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/Rahul08319/Happy-Anniversary.git
cd Happy-Anniversary
```

### 2. Run locally
Since the project is completely self-contained with pure HTML5, CSS3, and JavaScript, you can open `index.html` directly in any modern browser:

```bash
# On macOS / Linux
open index.html

# On Windows (PowerShell)
Start-Process index.html

# Or via any local server:
npx serve .
```

### 3. Automated GitHub Pages CI/CD
This repository includes a preconfigured GitHub Actions workflow in [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml). Any push to `main` automatically builds and deploys the latest version to GitHub Pages:
```text
https://rahul08319.github.io/Happy-Anniversary/
```

## 🛠️ Architecture & Technology Stack

- **Design Language:** Apple Human Interface Guidelines (Cupertino 2025/2026 Liquid Glass)
- **Frontend Core:** Pure Semantic HTML5, Modular CSS3 Custom Properties (Variables)
- **Canvas Physics Engines:** High-DPI HTML5 Canvas (`fireworksCanvas`, `confettiCanvas`, `cursorCanvas`)
- **Audio Synthesizer:** Native Web Audio API (`AudioContext`, `BiquadFilterNode`, `OscillatorNode`)
- **Typography:** Apple SF Pro Fallback + Cormorant Garamond & Plus Jakarta Sans
- **Icons:** Font Awesome 6 + SVG Glyphs
- **Automation:** GitHub Actions CI/CD for continuous GitHub Pages deployment
- **Dependencies:** 0 External build tools, 0 Framework overhead, 100% lightweight & instantaneous load
